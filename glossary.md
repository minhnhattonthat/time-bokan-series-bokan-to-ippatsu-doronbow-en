# Glossary - Time Bokan Series: Bokan to Ippatsu! Doronbow

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.
Seeded from `../time-bokan-series-bokan-desu-yo-en/glossary.md` (same series, same rulings); keep both consistent.

## Rulings (asked of the user once; options and reasons in docs/decisions.md)
- Honorifics: kept, hyphenated. Name order: Western (given name first).
- Romanisation source: official English names where they exist, else an earlier fan patch, else Hepburn without macrons.
- Credits: English.
- Register / flavour: slapstick parody of the Time Bokan anime; keep the villains' catchphrases punchy. Sound effects:
  spoken grunts and cries as written words ("Gaaah!"); no bracketed effect captions.
- Spelling: American.
- Abbreviations: full names and terms everywhere, prefer engine changes over shortening.
- Graphics text: all translated. The ボカンと一発!ドロンボー logo stays Japanese (no official English logo).

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> '...', ・・・ -> ..., ！？ -> !?
- Stage cards end on a character catchphrase (だコロン, だペッチャ): keep it as a verbal tic ("Koron", "Peccha").
